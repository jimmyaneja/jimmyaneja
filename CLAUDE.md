# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Environment

This project uses a Python 3.11 virtual environment located at the repo root. Activate it before running anything:

```bash
source bin/activate
```

## Running the app

```bash
python app.py
```

## Installing dependencies

```bash
pip install <package>
```

## Project structure

This is an early-stage Python project ("first agent") with a single entry point `app.py`. The `lib/` and `bin/` directories are the virtual environment and are not part of the application source.
